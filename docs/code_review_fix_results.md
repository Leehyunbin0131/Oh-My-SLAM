# 주행·지도 콘솔 수정 검증 결과

사용자가 기록한 실패를 재생하면 기존 DWB는 전역 경로가 시계 방향 회전을 지정한 첫 시점에 반시계 방향으로 0.01579 rad/s를 명령했다. 제자리 회전 구간의 방향이 후보 점수에 반영되지 않았고, 이전 회전 이력이 올바른 방향의 후보를 계속 배제할 수도 있었다. 수정 후 첫 명령은 −0.30 rad/s였다. 두 주행의 이력을 유지한 재생에서 84개 시점 모두 경로의 지시 방향과 일치했다.

기준 소스는 `72d3860`, 제품 수정 커밋은 `453f9da`, 정지 관측과 모의 브리지 검증은 `bad2758`·`d3056d6`, GUI 배치는 `ead96bb`, 탐색 설정은 `82a0759`·`32bba33`, 세션 모니터 설정은 `26f28af`, FollowPath 중단 시 명령 폐기는 `c175e1f`, 정지 중 AMCL 재측정은 `3eeb453`에 반영했다. 시뮬레이션 운용 상한은 **35.0 RPM**이다. 차륜 반지름 0.068 m에서 직진 0.2492 m/s에 해당한다. 좌우 차륜 상한과 별도로 회전 속도를 0.50 rad/s로 제한한다. 아래 결과에서 ‘완료’는 기재한 입력과 판정 기준을 통과했다는 뜻이다. 실제 브리지 회로와 차체를 주행시킨 결과는 별도 항목으로 표시했다.

## 장애물 앞 정지와 목표 결과

닫힌 게이트에서는 경로를 따르던 내부 액션의 종료를 확인해 이전 속도 명령을 폐기했다. Nav2가 한 번 대기하고 재계획한 뒤, 게이트가 비용지도에 표시된 시점에서 4.668초 만에 경로 부재로 목표를 종료했다. 가려진 낮은 장애물은 기억에 남았고, 다시 관측한 깊이 영상 5장(92.5–92.9초)에서 빈 공간이 확인된 뒤 삭제됐다. 원본 관측 시각 93.2초의 기억 스냅샷에서 삭제를 확인했다.

**추가 횡단 장애물 코스(I8)는 원래 목표까지의 자동 주행에 실패했다.** 차체가 정지한 뒤 횡단 상자가 깊이 카메라의 바닥 시야를 가렸다. 깊이 영상은 계속 도착했지만 지면 추정 상태가 `ground_not_established`로 바뀌었고, 안전 감시기가 목표를 취소했다. 동일 차체 자세와 상자 위치를 재현해 검사한 두 장면에서 바닥 평면과 1 cm 이내인 점은 2,000개 표본 중 1,919개와 0개였다. 이 코드의 복구 조건은 정상 관측 회복, 명시적 재활성화, 새 목표다. 횡단 뒤 원래 목표로 자동 복귀한 기록은 없으며 이 실행의 후속 단계는 미실행이다. 별도의 주행에서 깊이·라이다 단절 후 정지와 새 목표 없는 재출발 방지, GUI에서 저장 지도 AMCL 전환은 통과했다.
